# 📗 Week 02 — Pandas Hands-On: Data Manipulation & Analysis

This directory contains the **Week 02** lab work for the Machine Learning course at SRM University AP.

---

## 📝 Lab Overview

**Notebook**: `Pandas_HandsOn_Student_Lab_Completed.ipynb`

The lab covers essential Pandas operations for data manipulation and exploratory data analysis:

| Topic | Description |
|---|---|
| **DataFrames & Series** | Creating, inspecting, and understanding Pandas data structures |
| **Indexing & Selection** | `.loc`, `.iloc`, conditional filtering, and boolean indexing |
| **Data Cleaning** | Handling missing values, duplicates, and type conversions |
| **Aggregation & Grouping** | `groupby`, `agg`, pivot tables, and cross-tabulations |
| **Merging & Joining** | Concatenation, merge operations, and multi-source data integration |
| **Visualization** | Basic plotting with Pandas built-in methods |

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Libraries**: Pandas, NumPy, Matplotlib
- **Environment**: Jupyter Notebook / Google Colab
