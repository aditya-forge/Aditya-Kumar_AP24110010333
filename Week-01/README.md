# 📘 Week 01 — NumPy Hands-On: Array to Image Analysis

This directory contains the **Week 01** lab work for the Machine Learning course at SRM University AP.

---

## 📝 Lab Overview

**Notebook**: `NumPy_HandsOn_Array_to_Image_Analysis_Student_Lab_v2.ipynb`

The lab covers fundamental NumPy operations progressing from basic array creation to real-world image analysis:

| Topic | Description |
|---|---|
| **Array Basics** | Creating, indexing, slicing, and reshaping NumPy arrays |
| **Mathematical Ops** | Element-wise operations, broadcasting, and aggregations |
| **Linear Algebra** | Dot products, matrix multiplication, determinants |
| **Image as Array** | Loading images as NumPy arrays, pixel manipulation |
| **Image Analysis** | Grayscale conversion, cropping, filtering, histogram analysis |

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Libraries**: NumPy, Matplotlib, PIL/Pillow
- **Environment**: Jupyter Notebook / Google Colab
